ROOT-CAUSE DIRECTION
Current R12R8 recovery quiesces DMA then executes HAL_I2C_DeInit()+MX_I2C2_Init().
The persistent 35-36 ms HOST_RESET duration with zero successful recovery is consistent with I2C BUSY remaining asserted / a slave holding SDA low. Reinitializing the peripheral does not electrically clock a stuck slave out of that state.

R12R8R2 CHANGE
Only the LiDAR recovery path is functionally changed:
- Deinit I2C2.
- Temporarily configure PB10=SCL / PB11=SDA as open-drain GPIO.
- If SDA is low, pulse SCL up to 9 times.
- Generate explicit STOP.
- Verify SCL and SDA are both released HIGH.
- If still stuck, do NOT enter MX_I2C2_Init; retry later with existing bounded recovery cadence.
- If clear, force/release I2C2 peripheral reset, then run normal MX_I2C2_Init and restart acquisition.
- Intentional GPIO pulse time is bounded below ~120 us.
