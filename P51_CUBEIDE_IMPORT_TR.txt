Adimlar:
1. ZIP'i yeni bos klasore cikart.
2. CubeIDE -> File -> Import -> Existing Projects into Workspace.
3. P51 klasorunu sec.
4. Project -> Clean...
5. Build Project.
6. 0 error ve RAM/Flash overflow olmadigini dogrula.
7. Yeni P51 ELF'ini karta flash et.
8. Aktuator/pnomatik enerji kapali ilk bench testini yap.
9. UART:
   python -u monitor_uart_p51.py --port COM8
