   one scalar correction per 200 Hz correction service call.
2) 10 Hz batch start cadence preserved by the existing decimation counter.
3) Post-origin stationary detector requires |vz| <= 0.15 m/s.
4) If |vz| crosses the limit, stationary state + pending phase are released
   immediately so ZUPT cannot pull an actual powered-descent velocity to zero.
5) P50 fast masked-ZUPT Joseph, P48 gravity sparse Joseph, covariance rollback,
   vertical recovery, SD FIFO/backpressure and public z/vz guards remain.
6) SD format remains V14 / 384 B / 200 Hz.
7) UART becomes TGY62 / V62 / 258 fields.
