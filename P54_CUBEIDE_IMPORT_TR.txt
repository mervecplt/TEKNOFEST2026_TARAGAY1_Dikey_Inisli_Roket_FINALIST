P54 CubeIDE import:

1) ZIP'i yeni bos bir klasore cikarin.
2) STM32CubeIDE -> File -> Import -> Existing Projects into Workspace.
3) TGY_V8_19M_P54_BARO_RATE_GUARD_IMU_REG_DIAG projesini secin.
4) Project -> Clean...
5) Build Project.

Beklenen firmware kimligi:
  FW 8.19M-P54-BARO-RATE-GUARD-IMU-REG-DIAG
  TGY UART FLIGHT DIAGNOSTICS V65
  $TGY65

Target build kullanicinin CubeIDE ortaminda yapilmalidir.
