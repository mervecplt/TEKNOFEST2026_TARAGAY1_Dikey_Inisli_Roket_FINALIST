===================================================
Firmware: 8.19M-P81-DUAL-ADC-ROBUST-FEEDBACK
Purpose : DO-NOT-FLY bench validation of robust needle position feedback

1) INPUT FROM P80
-----------------
P80 showed ADC1 and ADC2 observing the same unstable PC1 signal, while ADC
conversion timeouts remained zero and VREFINT was comparatively stable. P81
therefore treats the main risk as an external/common analog feedback problem,
not a single ADC peripheral fault.

3) ROBUST FEEDBACK DESIGN
-------------------------
PASS - ADC1 + ADC2 long-sample PC1 pair at ~500 Hz.
PASS - Pair hard reject when |ADC1-ADC2| > 30 ADC10.
PASS - Accepted pair candidate = average(ADC1,ADC2).
PASS - 7 accepted-sample median; minimum 5 samples before valid feedback.
PASS - Large median jump threshold = 35 ADC.
PASS - Large level change requires 3 persistent median samples within +/-20 ADC.
PASS - Confirmation delay is nominally ~6 ms at 500 Hz.
PASS - Pending large jump makes feedback INVALID; last-good is held.
PASS - Normal path uses 3 ADC deadband + 1/4 IIR.
PASS - Separate confidence score; valid threshold = 60%.
PASS - 1 s raw-vs-filtered p-p and max-step diagnostics.
PASS - VREFINT 1 s p-p retained.
PASS - Combined ADC timeout count retained.
